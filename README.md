# verilog-calculator-with-bcd-conversion

This project implements an FPGA-based digital calculator capable of performing basic arithmetic operations on two 4-bit binary inputs. The system is designed using Verilog HDL and deployed on the Nexys4DDR FPGA board.

The calculator supports addition, subtraction, multiplication, and division, and displays results on a multiplexed 7-segment display after converting binary output into BCD (Binary-Coded Decimal) format.
